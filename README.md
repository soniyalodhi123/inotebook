# 📝 iNotebook - Secure Cloud Notes Application

A full-stack **MERN (MongoDB, Express.js, React.js, Node.js)** web application where users can securely create, read, update, and delete their personal notes from anywhere.

## ✨ Key Features
- **Secure Authentication:** User Signup & Login with JWT (JSON Web Tokens) and Bcrypt password hashing.
- **CRUD Operations:** Add, Edit, Delete, and Copy notes instantly.
- **Real-Time Search:** Filter notes by title, description, or tag.
- **Dark / Light Mode:** Eye-friendly theme switcher.
- **Bilingual About Page:** Switch between English and Hindi seamlessly.
- **Toast Notifications:** Instant bottom-right alerts for every user action.

## 🛠️ Tech Stack
- **Frontend:** React.js, Context API, Bootstrap 5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
